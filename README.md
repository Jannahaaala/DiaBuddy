# DiaBuddy
DiaBuddy: a web app that helps people with diabetes calculate insulin doses, follow meal guides and stay on track with reminders and notifications.

## Features

- **Insulin calculator**: works out an insulin dose from [carbohydrate intake, current blood sugar level and target range.
- **Meal guide**: suggests meals and shows nutrition information to help users plan what they eat.
- **Notifications and reminders**: timely alerts for [insulin doses, meals, blood sugar checks].
- **Blood sugar tracking**: record readings and review them over time.
- **User account**: all of the user's past information is recorded and stored in the database.

## Tech stack

- PHP
- HTML and CSS
- SQL / MySQL
- XAMPP (local Apache and MySQL server)

## Getting started

1. Install [XAMPP](https://www.apachefriends.org) and start **Apache** and **MySQL** from the control panel.
2. Copy the project folder into XAMPP's `htdocs` directory.
3. Open phpMyAdmin (`http://localhost/phpmyadmin`), create a database named `[database name]`, and import `[your .sql file]`.
4. If needed, update the database connection details in `[config file name]`.
5. Open `http://localhost/[project folder]` in your browser.
